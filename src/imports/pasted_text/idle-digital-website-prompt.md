# IDLE DIGITAL — FIGMA WEBSITE MASTER PROMPT

Design and prototype a complete responsive website for **Idle Digital**, a creative digital studio.

The website should feel like a premium independent creative agency rather than a generic marketing company or SaaS website.

The creative direction is:

**Editorial Digital Playground**

The experience should combine:

* Editorial layouts
* Oversized typography
* Strong grid systems
* Minimal UI
* Large portfolio imagery
* Purposeful motion
* Experimental but usable interactions
* High contrast
* Clean white space
* Occasional immersive blue sections
* Small orange interaction details

The website should feel:

**Creative. Confident. Digital. Young. Premium. Intentional.**

Avoid generic agency templates, rounded SaaS cards, excessive gradients, glassmorphism, generic illustrations, random blobs, and unnecessary visual clutter.

The work and typography should be the visual focus.

# 6. GLOBAL INTERACTION LANGUAGE

Interactions should feel sophisticated but playful.

Use:

* Smooth scrolling
* Subtle text reveals
* Image scale on hover
* Typography movement
* Cursor-based interaction
* Horizontal text movement
* Project image reveals
* Animated underline or arrow states
* Section color transitions

Avoid excessive parallax.

Avoid animations that reduce usability.

Motion should feel deliberate.

Recommended animation timing:

Fast interaction:
150–250ms

Section interaction:
400–700ms

Large transitions:
700–1000ms

Use smooth easing.

# RESPONSIVE BEHAVIOR

Desktop hero typography may use 100–180px display sizes depending on line length.

Tablet should scale substantially but maintain the same visual hierarchy.

Mobile hero should remain large and graphic.

Do not reduce mobile headline typography to generic 40px website text.

Aim approximately 50–72px where layout permits.

For project layouts:

Desktop:
asymmetric editorial grid.

Mobile:
stack projects vertically but maintain varied image proportions.

Service rows:

Desktop:
interactive horizontal accordion.

Mobile:
vertical tap-to-expand sections.

Case studies:

Allow large imagery to remain edge-to-edge on mobile.

# FINAL DESIGN GOAL

The final Idle Digital website should not look like a template.

It should feel like the digital home of an independent creative studio with a clear point of view.

The site should communicate creativity before the visitor reads every sentence.

Typography and project work should do most of the visual storytelling.

The experience should move between restraint and expression:

**WHITE → WORK → BLUE → WHITE → BLACK**

The overall impression should be:

**Minimal enough to feel premium.**

**Bold enough to feel memorable.**

**Interactive enough to demonstrate digital capability.**

**Structured enough to remain easy to use.**

Above all:

**Make Idle Digital feel anything but idle.**

# IDLE DIGITAL — WEBSITE REFINEMENT + ARCHITECTURE UPDATE

Update the existing Idle Digital website.

DO NOT redesign the website from scratch.

The current visual direction, typography scale, overall editorial aesthetic, brand colors, logo usage, animations, and major homepage structure are worth preserving.

This update should focus on:

1. Simplifying the website architecture
2. Combining Services + Process + Plans into one page
3. Removing Quiz from global navigation and footer
4. Refining the visual identity so the site feels more distinctly Idle Digital
5. Improving imagery and visual rhythm
6. Correcting outdated About and Contact content
7. Removing fabricated plan limits and promises
8. Improving responsiveness across every page
